# Klasifikasi ISPA Menggunakan SVM

Project ini bertujuan untuk mengklasifikasikan penyakit ISPA (Infeksi Saluran Pernapasan Akut) menjadi kategori **Ringan** dan **Berat** menggunakan metode **Support Vector Machine (SVM)**.

## 📊 Dataset
Dataset berisi data pasien seperti:
- Jenis Kelamin (JK)
- Usia
- Gejala (demam, batuk, dll)
- Kategori ISPA

## ⚙️ Metode
Metode yang digunakan:
- Preprocessing data (encoding & normalisasi)
- Pembagian data training dan testing
- Algoritma Support Vector Machine (SVM)

## 📈 Hasil
Model berhasil melakukan klasifikasi dengan akurasi sekitar **91%**.

## 🛠️ Library yang Digunakan
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn
